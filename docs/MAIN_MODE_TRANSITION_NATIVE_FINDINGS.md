Assumptions include normal opaque-call returns, valid nonexception memory accesses, immutable code/tables and original import-loader bindings. Candidate anchors are diagnostic data identities, not runnable helper implementations.

3. Each role address has precisely the declared source symbol and its generated anchor symbol. Identity now requires that exact pair with matching section, offset, flags and producer; any third or unrelated collision rejects.

These changes repair read-only measurement adapters. They do not modify accepted matching rules or historical receipts.
