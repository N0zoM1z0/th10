For effect mode zero, color*2+0x11 is also one native 32-bit script-ID word.

Previously both source expressions converted high-bit unsigned arithmetic results to int, an implementation-defined operation. This revision computes the unsigned nextIndexBits in the existing branch and reads it as a signed int via the corresponding integer type (allowed C++ type alias); effectScript is published through the corresponding unsigned int type of its existing signed field.
