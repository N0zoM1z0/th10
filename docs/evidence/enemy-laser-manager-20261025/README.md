## Reproduction and operational lessons

Use `scripts/repo-python`, one CPU, nice10 and a bounded timeout with durable
log/exit files. `reproduce.py --trial literal --output-dir build/UNIQUE` performs
a fresh isolated cold; `--prepare-only` checks the overlay without compilation.
Canonical focused replay uses units `enemy-laser-manager-initialize` and
`enemy-laser-manager-create`. The comparator requires a fresh target hash,
complete PDB extent, exhaustive fields, literal bytes and all local targets.

New lifecycle TUs using Main/WinBase follow the established **Main.hpp-first**
include order. JSON serialization recursively stringifies dictionary keys
before expensive work; `default=str` handles values only. Cold guards should
snapshot mutable output directories **before** replay or use a distinct output;
a later snapshot preserves only the new proof, not the replaced bytes.
